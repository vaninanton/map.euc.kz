# Changelog

## 2026-08-10 (документация и скиллы)

### Fixed

- **Скилл `supabase-clone-prod` больше не сливает прод-PII в git.** Он писал дамп прода в `supabase/seed.sql` и «защищал» его добавлением пути в `.gitignore`. Но файл **отслеживается** git (в `.gitignore` есть `!supabase/seed.sql`), а на отслеживаемые файлы gitignore не действует — прогон скилла затирал курируемый seed (только точки и маршруты, без персональных данных) дампом с телеграм-идентификаторами, координатами и аватарами. Теперь дамп идёт в `supabase/backups/` (игнорируется целиком, проверка через `git check-ignore` до дампа) и грузится в локальную БД отдельным `psql`; `seed.sql` не трогается
- Заголовки CHANGELOG — только дата, без `[Unreleased]` и номеров версий
- Актуализирован `CLAUDE.md`: `npm run build` не проверяет типы (это `build:check`), `supabase/schema.sql` не существует, миграций 28 а не 16, в adminApi нет `getAdminGeoData`, добавлены `src/app/`, `components/ui|icons`, `admin/utils`, `mapLayerRegistry`, `layerVisibility`, `lib/analytics`, вход по пасскею, `sitemap.xml` и часовой дамп
- Мелкие расхождения в скиллах: `eslint.config.ts` → `eslint.config.js`, `tsc --noEmit` → `tsc -b --noEmit` (корневой конфиг — только references), порт e2e 4174, счётчики тестов, `.claude/skills/` давно закоммичен

### Changed

- Документация для разработчиков переведена на английский: `docs/`, `CLAUDE.md`, `AGENTS.md`, `.claude/skills/`. По-русски остаются интерфейс, комментарии в коде, CHANGELOG, описания коммитов и `README.md`
- `update-deps` сначала проверяет открытые PR от Dependabot — он и так группирует minor/patch ежедневно

## 2026-08-05 (sitemap и кэш дампа)

### Added

- `/sitemap.xml` — карта сайта из 329 адресов: разделы, 65 точек, 43 маршрута, 212 велодорожек, события. Собирается на лету, поэтому точка из админки попадает туда без деплоя
- `public/robots.txt` со ссылкой на карту сайта; админка и страницы райдеров (живые геопозиции — персональные данные) закрыты от индексации

### Changed

- Вместо покомпонентного кэша данные точек и маршрутов забираются **одним дампом на час** (23 КБ на 108 сущностей). Краулер приходит по свежепошаренной ссылке, которую в этом дата-центре ещё не запрашивали, — при покомпонентном кэше это всегда промах, при дампе попадание. Сущность, которой в дампе нет (создали только что), запрашивается точечно, промахи кэшируются на 5 минут
- **Фото точки идёт в превью как есть, без проверки веса** (решение владельца проекта). Telegram тянет до 5 МБ и ужимает сам; в WhatsApp тяжёлое фото может остаться непоказанным. Заодно ушёл HEAD-запрос — половина накладных расходов функции

### Fixed

- ESLint игнорирует `.wrangler`: после локального запуска `pages dev` линтер спотыкался о временные бандлы и ронял pre-commit

## 2026-08-05 (SEO)

### Fixed

- **Канонический адрес больше не врёт**: статический `<link rel="canonical" href="https://map.euc.kz/">` объявлял главную канонической для **всех** страниц сразу (index.html отдаётся на любой путь), то есть просил Google выкинуть из индекса и точки, и маршруты. Убран из разметки; для `/m/...` правильный адрес проставляет Pages Function

### Added

- `favicon.ico` (16/32/48) и `favicon-32x32.png` — Google Search не поддерживает SVG-фавиконки и без них не показывает иконку сайта в выдаче
- JSON-LD на страницах объектов: точка описывается как `schema.org/Place` с координатами, маршрут и велодорожка — как `WebPage`
- `og:logo` — свойства нет в спецификации Open Graph и мессенджеры его не читают, добавлен ради SEO-валидаторов

### Changed

- Короткие описания дополняются контекстом проекта: «Вид на город» → «Вид на город. Мономаршруты — карта для райдеров на моноколёсах в Алматы: …» (124 символа против 12 — поисковики показывают 110–160)
- Данные сущности кэшируются на edge 5 минут: без кэша каждый заход на `/m/...` стоил запроса в Supabase плюс HEAD за весом фото (~150–200 мс сверх статики). Кэшируются именно данные, а не готовый HTML — иначе после деплоя можно было получить страницу со ссылками на удалённые бандлы

## 2026-08-05 (OpenGraph)

### Added

- Динамические OG-теги для ссылок на карту: `/m/point/11`, `/m/route/5`, `/m/bikelane/62` отдают краулерам человеческий заголовок — «Смотровая площадка Горный гигант — точка на карте», «Медео — маршрут на карте», «улица Валиханова — велодорожка на карте». Реализовано Pages Function с `HTMLRewriter` (`functions/m/[type]/[id].ts`): краулеры Telegram/WhatsApp/VK не исполняют JS, поэтому заголовок из React им не виден
- У точки с фотографиями превью — её первое фото вместо дефолтной картинки проекта, но только если фото легче 600 КБ: на превью тяжелее WhatsApp часто не показывает картинку вообще, а трансформация Supabase Storage на текущем плане недоступна (403). Тяжёлое фото откатывается на баннер проекта
- `index.html`: появились `og:image`, `og:image:width/height/alt` и twitter-теги — раньше `og-image.png` лежал в `public/`, но не был подключён ни одним тегом

### Changed

- `og-image.png`: 2848×1504 и 4.2 МБ → 1200×630 и 120 КБ (палитра 64 цвета). Прежний размер многие краулеры просто игнорировали, а 1200×630 — стандартное соотношение карточки
- OG-теги в `index.html` содержат абсолютные URL: краулеры не резолвят относительные пути (`og:url` раньше рендерился как `/`)

### Removed

## 2026-08-05

### Changed

- Хостинг переехал с GitHub Pages на Cloudflare Pages (проект `map-euc`, direct upload через `wrangler` из GitHub Actions). Домен `map.euc.kz` и origin не меняются, так что PWA у пользователей переживает переезд без переустановки

### Added

- `public/_headers`: `immutable`-кэш для хешированных бандлов, недельный для иконок, `no-cache` для `sw.js`, обязательная ревалидация HTML

### Fixed

## 2026-07-14

### Fixed

- Service worker: офлайн-навигация на непосещённый URL теперь падает на app shell (`index.html` из static-кэша) вместо браузерной страницы «Нет соединения»
- Service worker не регистрируется в dev (и разрегистрируется, если остался): cache-first отдавал устаревшие `/src/*`-модули и CSS до перезапуска dev-сервера
